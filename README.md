# 👨‍💻 Meu Portfólio Web Pessoal

Este repositório contém o código-fonte do meu site de portfólio. Desenvolvi esta *Landing Page* com o objetivo de centralizar meus projetos práticos, habilidades técnicas e informações de contato para oportunidades de estágio na área de Tecnologia da Informação.

🔗 **[Acesse o Portfólio ao Vivo Aqui](https://vitorbernardes-tech.github.io/Portf-lio/)**

---

## 🎯 Objetivo do Projeto

Criar uma vitrine profissional, responsiva e direta ao ponto para apresentar meu perfil como estudante de TI e desenvolvedor em início de carreira. O site foi projetado para destacar minha capacidade de atuar com soluções de ponta a ponta, desde a criação de APIs no back-end até interfaces visuais no front-end.

## ✨ Funcionalidades e Estrutura

* **Design Responsivo:** Layout adaptável que funciona perfeitamente em dispositivos móveis e desktops.
* **Single Page (Landing Page):** Navegação fluida e focada em uma única página, otimizando a experiência do usuário (UX) sem distrações.
* **Vitrine de Projetos:** Cards dinâmicos detalhando tecnologias e links para os meus repositórios e aplicações no ar (como a *Shape & Health API* e o *Formulário Interativo*).

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica de todo o conteúdo.
* **CSS3:** Estilização moderna, variáveis de cores (Dark Mode base), layout utilizando Grid/Flexbox e Media Queries para responsividade.
* **GitHub Pages:** Plataforma escolhida para hospedagem estática e deploy contínuo do projeto.
